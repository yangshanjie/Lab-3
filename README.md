# Lab-3
子域名收集实验作业

> 课程作业｜网络安全情报收集
> ⚠️ 合规声明：本次实验仅用于课程学习，全部采用**被动情报收集**，不进行主动扫描、DNS爆破、端口探测。实验目标为IANA官方演示域名 `example.com`，不对任何未授权资产探测，遵守《网络安全法》。

## 一、实验目的
1. 了解ZoomEye（钟馗之眼）网络空间测绘引擎的作用
2. 梳理ZoomEye同类测绘搜索引擎
3. 掌握安全优先的被动子域名收集方法
4. 记录搜索语句，保存实验截图

## 二、ZoomEye同类测绘引擎
ZoomEye用于检索互联网暴露主机、Web服务、端口、指纹、IoT资产。同类平台：
- FOFA（白帽汇，国内主流，语法相近）
- Quake鹰图（360）
- Hunter猎人（奇安信）
- Shodan（国外老牌设备测绘引擎）
- Censys（侧重证书、TLS资产测绘）
